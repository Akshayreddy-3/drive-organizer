📁 Drive Organizer

1 · Rename scanned PDFs

Reads each letter on this computer and names it "Company - From Sender". Nothing is uploaded.

2 · Upload to Drive

Puts each file in its company's folder, under this month and today's date.

Setup check

Everything here needs a tick before the app can do its job.

    Start automatically

    Keep Drive Organizer running quietly in the background whenever you are signed in to this computer, so opening the app or its page always works. Turn it off here at any time.

    Drive destination

    Open your destination folder in Google Drive and paste its link. It must contain one folder per company.

    Reading model server

    Renaming asks a small language model to find each letter's sender. Leave this empty to use Ollama on this computer, or paste the address of another computer that runs it (for example a Mac mini on your Tailscale network: http://100.101.102.103:11434). Only the letter's text and the name of the company it is addressed to are sent there. If the text does not show the sender, pictures of the first two pages are sent too, so the model can read a logo or stamp.

    Your companies

    The renamer only ever names a file after a company on this list. Put one address per line. The list is stored encrypted on this computer. Import accepts a CSV file with the name in the first column and addresses in the next columns.

    Quit

    Drive Organizer keeps running in the background after you close this page, so the page opens instantly next time. Quit stops it until you open the app again.
